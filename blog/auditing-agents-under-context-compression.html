Auditing Agents Under Context Compression

November 2026 · Krushna Dash

Long-running agents produce more history than a monitor can keep in context. The trace fills with file edits, tool calls, permission requests, denials, retries, and policy changes. Eventually the monitor receives a window or compressed memory in place of the full record.

The event that decides whether an action is allowed may already be outside that view. A summary can omit a revocation, soften a denial, or drop a repository version change as background detail. In that case, the monitor has been handed the wrong case file.

Missing evidence

Residue measures this loss. I care about whether a compressed history retains the event that governs an action and whether the monitor can point back to it. Readability is incidental.

The harness will generate fictional agent histories from typed events, including patch proposals, approval decisions, expiring grants, repository changes, and ordinary background work. Every event carries an ID, source, logical time, and relevant version. A deterministic replay oracle calculates the current authorization state. Ground truth comes from the event sequence itself instead of another model’s opinion.

A narrative summary often keeps the general story while dropping one old denial. A typed ledger is clumsier to read, but it may keep the exact transition. I want to measure that tradeoff directly.

Fixed-budget memory

Each underlying trace will be rendered five ways: a recent window, a narrative summary, a keyword-guided summary, a compact typed ledger, and an evidence-linked ledger with bounded retrieval. Every method gets the same total token budget. Retrieved evidence counts against it.

The monitor classifies the proposed action and cites the event IDs behind its decision. Those outputs receive separate scores. A correct label with the wrong citation gets credit for detection and fails the evidence check.

I will measure detection rate, false positives, retention of the decisive event, source-event retrieval accuracy, and inference cost. The citation requirement gives every label a path back to the trace.

Matched histories

The dataset uses paired histories with the same task and distractions. One earlier authorization fact changes between the pair. I can then move the decisive event farther back, lengthen the trace, or shrink the context budget and see where each representation breaks.

SLEIGHT-Bench, AuditBench, and ARGUS helped shape the evaluation. Residue narrows the problem to evidence preservation under a controlled context budget. I have completed the methods paper, conceptual figures, architecture, evaluation plan, and development specification. The trace harness and model comparisons are next.

My scientific ML work has made me wary of averages that bury the failure mode. Aggregate forecast error can hide one geographic basin where a model consistently misses. A monitoring score can hide the event that vanished from memory. With Residue, I want the score and the event ID.
